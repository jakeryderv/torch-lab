# torch-lab

learn and experiment with pytorch


## pytorch packages

| Package | Purpose |
|---|---|
| `torch` | Tensors, automatic differentiation, neural networks, and GPU computation |
| `torchvision` | Computer vision and image/video transformations |
| `torchaudio` | Audio transformations and signal processing |
| `torchcodec` | Decode and encode media for use with models |
| `torchdata` | Tools for loading and processing training data |
| `torchtune` | Fine-tuning large language models |
| `torchrl` | Reinforcement learning |
| `torchrec` | Recommendation systems |

#### complementary packages

| Library | What it adds | When I’d add it |
|---|---|---|
| `numpy` | Numerical arrays, data preparation, and exchanging data with tensors | Now |
| `matplotlib` | Display images, plot loss curves, and inspect predictions | Now |
| `tqdm` | Progress bars for training loops | Now |
| `scikit-learn` | Dataset splitting, evaluation metrics, and classical ML baselines | Early |
| `pandas` | Explore and clean tabular data or CSV files | When working with tables |
| `tensorboard` | Compare training runs through interactive loss and metric plots | Once you run multiple experiments |
| `optuna` | Automatically search learning rates, layer sizes, and other hyperparameters | After you understand manual tuning |
